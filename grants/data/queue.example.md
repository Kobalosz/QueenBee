# Grant Queue

The working list, read top-down every run. Setup copies this to `data/queue.md`. Keep each section
sorted by deadline, soonest first. One line per program per cycle.

Line shape: `- [ ] YYYY-MM-DD deadline · Funder — Program · Tier · $max · URL · note`

## Ready for approval
Drafted, linted, waiting for the owner's yes (approve mode). The doc in `applications/` holds
every answer. The owner approves in the Grants app and the next run sends it.

## Packages ready (for the client to submit)
Tier B. Each folder in `applications/files/` has a `CHECKLIST.md` with the remaining steps.

## For you
Things only the client can do: pay a fee, sign, send an inquiry letter, sign in to a portal,
answer a question the fact sheet cannot.

## Vetted, not yet started
Eligible and a good fit, waiting for a run with capacity.

## Watch (opens later)
Announced or forecasted but not open. Recheck on the opening date.

## Done
- [x] YYYY-MM-DD submitted · Funder — Program · $requested · SUBMITTED / AWARDED $X / DECLINED
